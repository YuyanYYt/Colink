# 后续维护

## 0.4.0 · 开源安装预览版

- MIT 源码、通用配置、安装/技术文档和双平台 CI；个人连接配置与运行数据不发布。
- 自包含 Apple Silicon DMG/ZIP，新包为菜单栏 agent，不占 Dock，不依赖源码目录。
- 用户自己的首次连接设置，密钥仅通过 stdin 本机保存，保持默认关闭和样例范围。
- 手动安装与已有 Agent 协助安装两种路径，校验、拒绝覆盖与权限确认分别执行。
- 当前只用 ad-hoc 签名；后续优先 Developer ID 签名/公证、Keychain/显式密钥轮换、
  跨 macOS 版本和 Intel 安装包验证，不把它们写成已完成能力。

## 0.3.3 · Colink 与有界历史

- 对外项目、菜单栏应用、CLI 和 MCP 服务统一为 Colink，原命令和连接标识保持兼容。
- 每个项目只保留当前与前一次快照，清理无引用源码和过期同步记录；旧数据库回收空页。
- MCP 改为默认读当前、可读前次、用内部随机标识固定分析，结果不含递增版本编号。
- get_diff 默认比较当前与前次；过期读取明确拒绝，刷新工具后需用新对话验证。

## 0.1.0 已实现

- Ruff、190 项测试和持续 stdio / 原有 HTTP 两套演示。

实证与保留产物见 [VALIDATION.md](VALIDATION.md)。不是公网部署或真实项目验收。

## 0.3.1 日常使用修正

- 连续相切的 SVG 连接链与圆润代码括号；菜单栏与应用标志共用连接几何。
- 精简原生面板：只保留连接状态、文件夹和操作，说明放在需要确认的时刻。
- 安装到 `/Applications`，普通应用元数据与自身 Launch Services 注册；运行仍为菜单栏模式。
- Finder 退出后重开及 Spotlight 安装路径索引已验证；四指手势/系统 Apps 窗口未实测。

## 0.3.0 已实现

- Code Connect 原生 macOS 菜单栏应用、主题适配毛玻璃界面与 SVG 品牌标志。
- 启动、真正关闭整条连接、系统文件夹选择；没有自动重连或开机自动启动。
- 原生应用不保存密钥，复用已授权的项目运行密钥与一个私有 Tunnel。
- 多目录分离的镜像与 profile，选择本身不采集，启动真实目录前显式确认共享。
- 控制请求 / 管道 EOF / 信号下的进程树关闭、单连接锁和停机修改恢复测试。
- 该阶段仅对样例进行完整网页源码验收；真实目录使用需用户主动确认。

## 下一阶段：按授权扩大使用范围

1. 用户明确选择真实目录及传给 OpenAI 的范围，先 `scan` 预览文件与排除项。
2. 使用新的独立数据目录/profile，不借用原来源的镜像或静默扩展已经确认的范围。
3. 对真实项目验证启动对账、长期修改/删除、断网和客户端重启，再记录网页证据。
4. 按需确认登录自动启动、密钥轮换/Keychain及备份，不扩大已实现的两份快照保留窗口。

ChatGPT 公共插件目录发布是另一个可选阶段：单独选择 HTTPS 域名、反向代理和 OAuth 提供方，
验证受保护资源发现、令牌与读取 scope。当前私有 Tunnel 不需要先完成这条公网路径。

## 按需求增加

- Python AST 定义查询，再考虑其他语言；不以文本搜索冒充精确引用分析。
- 大于 8 MiB 的项目，增加分片/暂存提交和可配置的容量限制。
- 更细的忽略规则与符号链接策略、Keychain 凭据、项目级权限。
- 数据库备份、数据容量诊断与明确批准后的其他清理。
- 更完整的客户端 freshness 心跳、网页连接诊断；登录自启/LaunchAgent 需单独确认。
- 教学文档继续沿用 Google Drive；按需要关联进度，无需复制文档服务。

未计划在当前 MVP 加入任意终端执行或远程修改本机文件。
