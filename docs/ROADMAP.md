## 0.3.3 · Colink 与有界历史

- 对外项目、菜单栏应用、CLI 和 MCP 服务统一为 Colink，原命令和连接标识保持兼容。
- 每个项目只保留当前与前一次快照，清理无引用源码和过期同步记录；旧数据库回收空页。
- MCP 改为默认读当前、可读前次、用内部随机标识固定分析，结果不含递增版本编号。
- get_diff 默认比较当前与前次；过期读取明确拒绝，刷新工具后需用新对话验证。
