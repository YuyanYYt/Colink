# M2：按请求 Python 数据流

目标本机版本：0.5.0b7 / build 27，以 M1 的查询、授权和一致性协议为基础。本模块
只静态解析已保存的 Python 文件，不执行、导入、下载被分析项目，不持久化数据流，
不添加守护进程或全仓库预热。Java/Vue/Spring 跨语言链路不属于本版保证。

## analyze_code 新模式

| 模式 | 作用 |
| --- | --- |
| data_origin | 从一个值向前追溯其来源 |
| data_impact | 从一个值向后追踪其可能影响 |
| data_path | 从源值到目标值寻找静态传播路径 |
| combined | 同一请求中返回结构和数据流，保持不同节点及边类型 |

选择器必须定位方法及值，不能只传一个变量名。方法用 symbol_id 或 path + qualname；
值选择器用三种严格形式。列号为 Python AST 的 UTF-8 字节偏移加一，行号从一开始。

```json
{
  "project_id": "从 list_projects 返回的项目",
  "mode": "data_path",
  "selector": {
    "path": "flow.py", "qualname": "entry",
    "value": {"kind": "parameter", "name": "value"}
  },
  "target": {
    "path": "flow.py", "qualname": "entry",
    "value": {"kind": "return", "line": 7}
  },
  "max_depth": 2
}
```

其他值选择方式：`{"kind":"occurrence","line":6,"column":14}`，或只用
`{"kind":"return"}`。多处返回、重复定义、同位置不同值不会自动选择，返回候选
后使用具体 symbol_id 或源码行列缩小范围。值节点 df_* 和调用上下文只在本请求中
有效；续查使用方法身份和源码位置。返回候选被裁剪后仍明确要求选择具体发生位置。

## 已实现语义

方法内处理形参、字面量、赋值/重赋值、读取、表达式转换、返回及有限 self.field。
同名变量按词法作用域区分；分支合并表示可能传播，条件本身不会自动成为所有返回
值的数据来源。确定终止后的语句不继续生成确认传播。

跨方法结合实际调用点的 AST 和已解析调用事实，绑定位置、关键字、仅位置、仅
关键字参数及可确定的常量默认值，再连接真实返回位置与调用结果。不同调用点有
独立上下文；恒定返回不自动继承所有输入。读取 callee 参数来源时使用入向事实。

数据边包括 DEF_USE、ASSIGN、TRANSFORM、RETURN_FLOW、ARG_TO_PARAM、
RETURN_TO_CALLSITE。边有源码位置、依据及 static/possible/unknown；结构 CALL
与这些边保持区别。未找到静态路径不证明实际运行不可达。

## 部分覆盖与资源

递归、多候选、动态调用、外部库、复杂展开参数、闭包、全局变量、装饰器、异步、
生成器及未知副作用报告部分覆盖。复杂循环和异常控制保持保守；确定 break 跳过
else，finally 确定的返回覆盖旧返回。字典/序列投影、解包、切片和下标变更不保证
精确值别名，传播候选标记 unknown；跨调用或接收者重绑定会失效字段证明。

默认深度 1、节点 50、边 100、输出 12,000 字符及计算 3,000 毫秒。最大深度 5、
节点 200、边 500、输出 50,000 字符及计算 10,000 毫秒；数据流支持 max_depth=0
表示不展开跨方法调用。深度表示从选定方法出发的最大调用距离。combined 结构与
数据流共享同一输出预算，不能把三个视图各自的额度相加。

请求内工作上限为 10,000 值节点、30,000 数据边、100 调用上下文；单方法每方向
最多读取 5,000 条调用事实，超过时明确部分覆盖。AST 沿用现有单文件大小/节点
上限。时间检查协作中断 Python 遍历，SQLite 进度回调中断查询；原生 ast.parse
返回后再次检查预算。索引等待、安全校验与响应裁剪不承诺整体三秒硬期限。

每条 SELECT 在短锁内提取，源码读取和 AST 在锁外；读入源码与发布 SHA/身份
匹配，请求结束仍执行原源码前后检查及索引发布身份复核。超时可返回已完成的局部
事实；源码变化、失效索引和缓存损坏不作为普通计算超时吞掉。请求结束释放解析
树与图，没有结果缓存。写入、终端、数据库和 300 秒滑动空闲流程没有新增限制。

短锁、共享前后校验、查询中源码/发布变化、损坏事实、预算、严格 MCP 参数和重启。
组件、完整 Live 查询及实际普通聊天验收分别记录，不能以单元测试代替网页证据。
