# CoLink 网页会话开发能力 · 已批准实施方案

更新：2026-10-07。用户已明确要求实施本方案，并在实施过程中追加端口、环境、数据库与中文引导。
本文件是当前实施范围。TERMINAL_EXECUTION_PLAN.md 与 TERMINAL_SANDBOX_DESIGN.md 的旧候选范围仅保留历史参考。
来源基线：CoLink 0.5.0b3，分支 `codex/colink-controlled-write`；软件恢复锚点保持 `anchor/colink-0.5.0b2-before-terminal-execution` 不移动。

## 选型与执行边界

首版采用 Python 自有协调器 + 原生 macOS Seatbelt + SRT **0.0.78** 任务辅助进程 + 有界 APFS 工作盘。
固定 SRT 提交 `6f0ce155ccb136bda33a8a72201fe7f54fe47d9b`；借鉴 Codex 0.160.1 固定提交
`d27764b82f7118f674371e6d6e76271d9d606edb` 的进程组、退出确认、有界 UTF-8 输出和受保护路径机制。
不增加完整 Codex 后端或 Rust 构建链。新增安装占用上限 **250 MiB**，以实际安装差值验收。

网页模型负责理解、调用、看错误、修改与重跑；CoLink 负责本机授权、作业、输出、缓存和恢复。
链路固定为 ChatGPT 网页 → 当前远程 MCP → CoLink 作业协调器 → 隔离开发进程 → 状态/日志。
HTTP 无状态；一次工具调用、浏览器刷新或断网不等于作业结束。不得以 HTTP session ID 识别聊天。
网页停止调用后，本机不调用第二个模型自动继续修复。

Python、npm、Maven 同期覆盖安装、测试、构建和服务，提供隔离内开发 Shell。
首版使用非交互管道，不提供 PTY、尺寸调整或交互输入；密码等输入必须通过本机配置，不塞进命令参数。

## 接口、授权与恢复

`execution_environment`、`execution_plan`、`execution_rehearse`、`execution_start`、`execution_status`、
`execution_output`、`execution_cancel`、`execution_list`。
显式 `project_id`；服务端不透明计划/作业 ID；绑定源目录身份、权限 epoch、输入/工具链/配置摘要。
启动重试返回原作业，同 ID 改内容拒绝。回执 24 小时、总量 32 MiB；过期必须重新规划。
初始输出采集最多 2 秒；查询每次最多 64 KiB、等待最多 20 秒。
计划/预演/执行元数据反映真实副作用；本机授权不替代 ChatGPT 客户端动作确认。

执行许可默认关闭，独立于受控写入。一次本机授权覆盖选择的项目、公共包源和注册端口。
扩展目录/网络/端口重新规划与本机批准。撤权、切换项目、主控失联、退出停止相关作业。
重启只标记中断，不自动执行或重新收养旧 PID。状态区分退出成功/失败、超时、取消、停止中、停止未确认、重启中断。
进程存活、TCP 可连接、HTTP 应用健康分别展示。

每次静态检查计划；生命周期脚本、安装、生成器和权限变化触发同等隔离预演。
普通测试/构建执行一次，预演的真实结果复用，不能重复消耗。退出 0、没有拒绝日志不证明安全。

## 原文件、隔离与预算

执行使用校验的临时输入。原项目修改统一经过 WriteCoordinator 的哈希检查、声明路径和恢复记录。
不恢复长期完整镜像；任务输入有期限。任务作业独立于单个活动写任务，写回阶段串行协调。
环境白名单、明确工具路径、关闭继承描述符；不继承主控密钥、用户 Shell 配置、控制 socket。
拒绝链接/嵌套项目/凭据/`.git` 越界；保护控制目录及其祖先改名；拒绝 `system-fcntl 80/110`。
收紧 SRT 默认 Mach/XPC、本机绑定、临时目录，不套原始宽权限，也不以开放所有端口兼容工具。
依赖只访问批准公共包源，开发服务只绑定注册回环端口。私有源/外部 API/数据库另有本机配置。

| 项目 | 默认规则 |
| --- | --- |
| 并发 | 2 个开发服务 + 1 个有限任务，其余有界排队 |
| 有限任务 | 5 分钟执行截止时间，与读取等待分开 |
| 开发服务 | 工具/本机操作续期，20 分钟闲置停止 |
| 同一修复任务 | 5 轮或 20 分钟；网页负责修复逻辑 |
| 单作业工作盘 | 2 GiB 原生容量限制 |
| 依赖/构建缓存 | 每项目 2 GiB、全局 4 GiB，绑定平台/工具链/锁文件/配置 |
| 滚动输出 | 每作业 8 MiB、全局 64 MiB；明确游标与省略 |
| 已完成全日志 | 最终读取确认后清理；未读最多 10 分钟 |
| 失败摘要 | 64 KiB × 最多 16 项 / 1 小时 |
| 幂等回执 | 24 小时、32 MiB，结果不明不盲重跑 |
| CPU / 内存 / 进程数量 | 监督阈值与停止机制，明确为软限制 |

缓存只淘汰无活动引用条目。活动工作集超限返回容量错误，不删除使用中的数据，不扩大限制。
数据库数据、配置、凭据、锁文件、恢复记录与用户源码不属于派生缓存。

## 受控写回、移动与本地 Git

生成器形成差异；只写回最初授权的路径，来源变化/扩大范围即停止。源文件始终由 WriteCoordinator 修改。
`move_path` / `move_path_status` 支持文件、普通源码目录、图片字体资源；有界完整树、两端身份、无覆盖、两端恢复和 from/to 映射。
拒链接/硬链接/凭据/`.git`/嵌套项目/跨文件系统；case-only 两步唯一临时名，两阶段均记录恢复。
旧 schema/快照语义保留，移动后连续编辑和再移动要可恢复。
`git_plan` / `git_commit` 仅本地，精确本任务文件；隔离索引，HEAD/index/source CAS，保留用户已有暂存内容。
关闭 hooks/filters/helper/config 引出的执行入口，不推送、不 reset/clean、不合并用户其他工作。

## 追加一：端口冲突与旧服务

用户已选择：**CoLink 的本项目作业直接停止；之前手动启动的旧服务，在本机确认具体进程后停止。**
新增 `port_status`、`port_release_plan`、`port_release`；显示端口/地址/进程名/项目与作业归属，避免暴露命令参数或凭据。
绑定 PID 的出生身份、用户、当前项目目录与监听端口。停止前再验，端口/PID 被复用不能误停替换者。
未知、系统或其他项目进程不自动停止。网页可经现有受控写入修改前后端配置，再按新端口重新规划。
本机确认是针对可审核的具体旧服务；不能用授权项目运行代替任意全机 kill 权限。

## 追加二：真实环境与虚拟环境

网页先查询实际 Python / Node/npm / Java/Maven / 数据库客户端的路径、版本与可用性，避免假设不存在的环境。
不返回主机全量环境变量、Shell 配置或凭据。缺失工具给明确中文步骤，不自动安装全局软件。
Python 能在本任务/项目的有界隔离区创建独立 venv，相关编辑、依赖安装、测试和重跑复用相同环境。
环境绑定解释器版本、平台、锁文件和配置，不串项目；不改主机全局 site-packages。
npm 使用项目依赖；Maven 使用项目缓存仓库和实际 JDK。可用二进制与真实运行分别验收。

## 追加三：数据库与中文引导

用户选择 **复用已有数据库 + PostgreSQL/pgvector 默认推荐**；优先通过受控终端客户端/迁移工具完成管理。
MySQL、PostgreSQL 和向量存储接入能力列入范围；pgvector 的可用性必须在真实 PostgreSQL 连接中查询，不能由客户端存在推断。
独立管理数据库实例作为已存在环境不能满足需求时的后续路径，不默认安装/替换/重启用户数据库。

本机配置项目专用连接（类型、准确端点、库/schema/collection、TLS、项目角色）；凭据不进入聊天、代码、日志或命令参数。
网页读取连接状态、客户端/驱动能力与引导，通过获准端点在隔离任务中运行迁移、seed、后端与验证。
旧数据库需明确绑定项目范围；非项目专用管理员角色不直接交给项目脚本。数据库授权与一般服务端口授权分开。
建库、扩展安装与既有数据迁移按本机配置的具体范围；不能因“项目需要数据库”误改现有业务库。

新项目验收包含实际连接、迁移结果、写入/读取测试数据、后端接口与重启后数据持久性；向量项目还包括实际向量写入/检索。
业务没有完成前只报告已验证部分，不以静态页面、mock API 或开放端口替代数据库闭环。
提供中文分步教学：检测现状 → 选择数据库 → 创建项目角色/范围 → 本机配置 → 迁移 → CRUD/向量验证 → 排错。
原生保护 gate 未通过时不绕过沙盒执行数据库脚本；连接配置与引导仍可独立准备。

## 2026-10-07 追加：默认端口避开常见开发端口

CoLink HTTP CLI 默认 43116（菜单栏远程 MCP 走既有 stdio 隧道）；新开发服务默认登记 43117–43121，前端建议 43117、后端建议 43118。新建数据库实例建议 PostgreSQL/pgvector 43122、MySQL 43123、Qdrant 43124。启动前仍必须检查实际占用；这些数字不能保证永久免费。已有数据库连接使用实际端口，已运行的用户服务不会自动停机或改端口。端口更换通过已有受控配置写入和重新规划完成。

原生验证发现 Seatbelt localhost bind 会允许 wildcard bind。服务采用 CoLink 可信进程绑定明确 127.0.0.1 的登记端口，再转发到隔离任务的精确 Unix socket。项目进程没有 TCP bind 权限；Node 服务有受控适配器，Python/JVM 服务使用明确 Unix socket 接入。兼容性与网页闭环仍需实际验证。
