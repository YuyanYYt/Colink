# 安装与使用 CoLink

当前公开版本为 **0.5.0 Beta 2（`0.5.0b2`）**，使用原文件按需直读、多项目管理和
默认关闭的受控写入。旧 0.4.1 安装包仍保留在历史发行页，使用只读镜像，不具有
新版写入能力。日常读取、写入和 Diff 见 [LIVE_USAGE.md](LIVE_USAGE.md)。

## 推荐：直接安装 macOS 应用

安装包支持 **Apple Silicon（M 系列芯片）和 macOS 14 或更新版本**。
Intel Mac、Windows 暂无对应图形安装包；macOS/Linux 可使用源码 CLI。

1. 打开 [0.5.0 Beta 2 下载页](https://github.com/YuyanYYt/Colink/releases/tag/v0.5.0b2)。
2. 下载 `Colink-macos-arm64.dmg`，双击打开，将 `Colink.app` 拖入“应用程序”。
   也可下载 ZIP，解压后把应用放入 `/Applications` 或 `~/Applications`。
3. 从 Finder“应用程序”打开 **CoLink**，点击菜单栏图标。
4. 点击“首次连接设置”，填写你自己的 Tunnel ID 和隧道运行密钥。
5. 保存后仍保持关闭；先使用自带样例验证，再选择项目或工作目录并手动启动。

应用包含 Python、锁定的 MCP 运行依赖和官方隧道客户端，不需要先安装 Python、
uv 或 Node。运行时只显示菜单栏图标，不占 Dock；仍可从“应用程序”或应用搜索打开。
打开应用本身不启动连接，也没有开机自启。

### 系统安全提示与文件校验

这是 Beta 预览版，仅采用 ad-hoc 签名，**未完成 Apple Developer ID 签名或公证**。
macOS 可能提示无法验证开发者。核对来源和校验值后，是否使用系统提供的单个应用
“仍要打开”入口由你决定；安装脚本和 Agent 不会清除 quarantine、关闭 Gatekeeper
或绕过系统警告。

发行页提供 `SHA256SUMS`。全部安装文件在同一目录时执行：

```sh
shasum -a 256 -c SHA256SUMS
```

若只下载 DMG，执行 `shasum -a 256 Colink-macos-arm64.dmg`，与清单中的同名值比较。
SHA-256 校验用于检查文件完整性，不等于 Apple 公证或独立的发布者身份认证。

## 升级已有安装

1. 在旧应用中点击“关闭”并退出，确认自有连接已经停止；不要覆盖正在运行的应用。
2. 保留 `~/Library/Application Support/Colink/` 内的设置、凭据和现有数据。
3. 将新版安装到原应用路径，替换旧应用。若你需要自行保留旧应用，放到明确位置；
   安装脚本仍拒绝自动覆盖，Agent 应先向你确认升级方案。
4. 重新打开后检查原连接设置和目录选择，在项目管理中确认要开放的项目。
   新版使用直读模式，不再为普通读取保存完整项目镜像，也不会自动删除旧镜像库。
5. 在 ChatGPT 原连接管理页刷新工具并新建对话。新版有 **15 项读取工具和 7 项
   任务工具**；写入仍关闭，旧 `rollback_write_task` 已移除。

新登记格式支持 schema 1/2。启用新版后，不应直接用旧 Beta 1 读取已升级的登记文件。
需要降级时先保存当前数据并检查兼容性，不通过删除数据目录“解决”迁移问题。
历史源码、安装包和说明见 [所有 Releases](https://github.com/YuyanYYt/Colink/releases)；
**历史包可下载不代表新版状态可直接交给旧版读取**。

## 只需首次完成：你自己的 ChatGPT 私有连接

CoLink 本身不调用模型，不需要模型调用密钥。隧道运行密钥只交给官方客户端；
拥有密钥不等于已获得 Tunnel 或 ChatGPT 工作区访问权限。

1. 在 [OpenAI Platform 私有隧道设置](https://platform.openai.com/settings/organization/tunnels)
   创建自己的 Tunnel，关联自己的组织与需要使用的 ChatGPT 工作区。
2. 准备该 Tunnel 的运行密钥，在 CoLink 的首次连接设置中填写。不要把密钥放进
   GitHub、聊天、截图、项目源码或命令参数。
3. 在 CoLink 手动启动。保持电脑联网和应用运行，不需要开放路由器或防火墙公网入站。
4. 根据自己的账号权限启用 ChatGPT 开发者模式，在插件/连接管理页添加自定义 MCP，
   名字填写 `CoLink`，选择 Tunnel 连接方式以及自己的 Tunnel。
5. 确认工具已发现，用新的对话读取自带样例。不要为测试自动开启写入。

入口名称、开发者模式和私有隧道的可用性，以你的账号页面和管理员策略为准。
账号不提供该连接方式时，本地 stdio 客户端仍可使用；CoLink 不会自动切换为公网代理。
官方资料见 [Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
及 [连接与测试](https://developers.openai.com/plugins/deploy/connect-chatgpt)。

每位用户独立运行 CoLink、配置自己的账号和连接。本仓库的 GitHub 发布不等于已上架
ChatGPT 公共插件目录，也不共享维护者的组织、密钥或个人连接。

## 第一次使用

先连接自带样例，在新对话中问：

> 使用 CoLink，只调用 list_projects，告诉我当前可读项目。

然后问：

> 查看样例 main.py，解释入口函数；先获取概览，再读取必要代码范围。

确认网页内容与本机文件一致后，再关闭连接，选择自己的项目或工作目录。项目管理中
只启用需要的项目；无 Git 的 Python/Java 项目可依据项目配置发现，空目录可手动登记。
同名项目用路径限定名区分，网页使用唯一项目 ID。不要直接共享 Home、系统目录、凭据
或其他人的私有源码。**查询到的源码会发送给 AI 客户端及其服务提供方。**

### 需要修改代码时

默认只有读取许可。你明确需要修改时，在本机打开“允许修改代码”，选择准确项目，
再向 AI 发出修改要求。可精准插入/替换、创建文件/目录和删除单个源文件，不能递归
删除或执行终端命令。本机开关与网页工具确认独立，不能保证所有账号都不弹确认。

修改前请用项目自己的 Git 保存重要稳定点。新版移除了主动代码回退；任务 Diff
只显示累计变化，不替代 Git 历史。完整写入流程与限制见 [LIVE_USAGE.md](LIVE_USAGE.md)。

### 可选：按问题自动匹配 Skill

按 [Skill 指南](CHATGPT_SKILL.md) 在账号内安装 `colink-code-context`。对于自己的
项目且缺少源码上下文的问题，可以自然提问，不必每次手动 `@` 选择；充分代码片段
或通用语法问题应直接回答。实际匹配由客户端决定，不保证每轮自动触发。

下载页提供对应版本的 Skill ZIP 备用包。上传格式以网页提示为准，编辑器方式是
已确认的安装路径。Skill 不自动配置连接、授权目录或成为强制系统提示词。

## 日常操作与数据

| 操作 | 结果 |
| --- | --- |
| 选择文件夹 | 仅选择项目/工作区，不自动连接 |
| 项目管理 | 发现、登记并分别启用需要的项目，新项目需本机确认 |
| 启动 | 启动直读 MCP 和出站私有隧道，写入默认关闭 |
| 允许修改代码 | 仅给本机明确选定的项目授予受控写入许可 |
| 关闭 | 撤销写入并停止本应用的连接，直到再次手动启动 |
| 收起面板 | 只收起界面，连接继续运行 |
| 退出应用 | 停止连接并退出；重开仍关闭 |

运行时更换工作目录前先关闭连接。休眠、断网或关机时网页不可用；重新启动后读取
实际已保存的文件。用户数据位于 `~/Library/Application Support/Colink/`，包括私有
配置、项目登记、派生索引和任务材料。密钥文件权限为 `600`，目前未使用系统钥匙串。

普通读取不保留完整项目正文；索引、Diff 起点及中断保护仍占空间并受预算约束。
旧镜像兼容入口仍保存当前和前一份状态。关闭、更新或卸载应用**不会自动删除这些
持久化数据**，不要把整个数据目录当作缓存清理。

## 从源码安装

准备 Git、Python 3.11+ 和 [uv](https://docs.astral.sh/uv/getting-started/installation/)。

```sh
git clone https://github.com/YuyanYYt/Colink.git
cd Colink
uv sync --locked
```

本地 stdio 客户端的直读、多项目和 HTTP 配置见 [CLI_USAGE.md](CLI_USAGE.md)；
从源码构建图形应用见 [MACOS_APP.md](MACOS_APP.md)。旧镜像和隧道源码配置另见
[LOCAL_HOST.md](LOCAL_HOST.md)。

## 常见问题

- **显示“已有连接”**：不要同时运行同一个 Tunnel；先停止原终端或应用里的连接。
- **网页工具仍是旧版**：重启后端，在原连接页刷新工具并新建对话；旧 Skill 副本也需
  单独更新，仓库文件不会自动同步到你的账号。
- **已有配置不能再次填写**：首次设置不提供静默覆盖。先关闭连接，检查自己的配置，
  不把密钥传给 Agent 或上传 Issue。
- **移动应用后配置不可用**：先将应用放到最终位置再配置；已配置后换位置需检查
  profile 绑定的解释器路径，不能照搬其他人的 profile。
- **源码没更新**：确认编辑器已经保存文件、询问的是正确项目；过期读取依据被拒绝时
  重新获取上下文，不把失败当作保存成功。

报告问题时请提供系统、芯片、版本、操作步骤和不含凭据的错误信息。
