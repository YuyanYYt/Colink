新版本可读取历史 JSON 和早期压缩缓存；首次结构查询后以新标记重新发布。
9150904 会跳过新标记的解析缓存，重新读取原文件并生成旧格式索引。
此路径已用 9150904 的实际源码在独立样例缓存上验证；不等于用户全部持久数据
和外部服务的整机回退验收。
