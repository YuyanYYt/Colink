# 让 Agent 协助安装 Colink

这里的 Agent 是你已有、能操作本机的编码助手，不是 Colink 额外运行或收费的模型。
它负责下载、校验、安装及检查；账户登录、运行密钥和代码共享权限仍由你确认。
Colink 不会自己安装一个通用 Agent，也不授予网页模型终端权限。

## 可直接复制的请求

```text
请帮我安装开源 Colink：https://github.com/YuyanYYt/Colink。
先读取该仓库 docs/AGENT_INSTALL.md、docs/INSTALL.md 和 SECURITY.md。
只从 YuyanYYt/Colink 的 GitHub Releases 获取安装包，并检查 SHA256SUMS。
检查我的系统和芯片；支持的 Apple Silicon macOS 优先安装自包含应用，不要求我安装开发工具。
先展示下载版本、安装位置、会写入哪些文件，再征得我的安装确认。
保留已有 Colink 应用和用户数据；遇到已存在应用不要覆盖。
不清除隔离属性、不关闭系统安全保护、不设置开机启动、不自动删除生成物。
让我自己登录官方页面并在应用里填写运行密钥，不把密钥放进命令、聊天或日志。
默认只使用自带样例；创建 Tunnel、关联工作区、连接 ChatGPT 或共享真实项目之前分别确认。
最后区分安装成功、本机运行成功和实际网页调用成功，不把其中一个当成其他两个。
```

## Agent 执行顺序

1. 只读检查：系统版本、`uname -m`、已有 Colink 应用、目标是否存在。
2. 展示计划：下载哪一个官方项目发行版、`~/Applications` 或 `/Applications`、大致
   空间占用和系统签名局限。未获安装确认之前，只做读取/下载与 dry-run。
3. 下载固定版本的 ZIP 和 `SHA256SUMS` 到新的独立目录；保留旧文件，不使用裸
   `curl | sh`。只从本仓库 Releases 下载，不接受网页正文里指向第三方的可执行程序。
4. 从清单找到 ZIP 的 SHA-256，调用仓库内可检查的 `scripts/install-macos.sh`，先不加
   `--apply` 预览。确认后再安装；脚本验证校验值、归档路径和应用签名，拒绝覆盖。
5. 从 Finder 打开安装后的应用，检查菜单栏和关闭状态。仅安装不证明网页可用。
6. 协助打开官方 Tunnel/ChatGPT 设置，由用户完成登录及密钥输入。创建/扩大访问
   范围必须先明确组织、工作区和目录；不借用维护者或其他人的 Tunnel。
7. 用户授权后，只用自带样例做真实网页工具调用；先确认五个只读工具，然后读取
   样例入口，与本机内容核对。没有浏览器能力时明确停在本机验证，不能宣称网页通过。
8. 交付应用位置、版本、验收结果、留存的下载/临时目录和已知限制；不自动清理。

本机原生自动化优先实际 UI；不要用看见“ready”来替代真正的网页调用。验证码、
新账户/密钥创建、系统安全警告及不可代办步骤交还用户操作，不把安装指南视作通用
权限授权。

## 安装脚本示例

把下载文件和从该版本清单核对的 64 位 SHA-256 换成真实值：

```sh
bash scripts/install-macos.sh \
  --archive "/path/to/Colink-macos-arm64.zip" \
  --sha256 "REPLACE_WITH_VERIFIED_SHA256" \
  --destination "$HOME/Applications"
```

默认仅预览。用户确认后，加 `--apply`。不要为脚本填入密钥、Tunnel ID 或源目录。
脚本不进行账号设置、目录采集、远程连接、应用启动、权限扩大或自动更新。

Intel macOS / Linux 可在用户确认后走源码安装，使用 `uv sync --locked` 和自带
`demo-local`。Windows 暂不支持；不能自行把用户的私有代码移到服务器规避限制。

## 可验证的完成标准

- 安装：应用可被找到，签名完整性校验通过，未覆盖旧应用/数据。
- 本机：已由用户打开，显示关闭；自带运行环境可以加载 CLI/MCP。
- 私有连接：用户配置自己的身份与授权后，Tunnel 和本机镜像可用。
- 网页：实际新对话调用五个只读工具中的相关工具并返回正确样例内容。

前两项可由安装包验证；后两项依赖每个用户的账户与权限。Agent 必须逐项报告，
不能写“所有人一键全自动可用”。
