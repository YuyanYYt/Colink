## 相对上一公开版的变化

- **统一读取与分析**：Live 使用 `read_code` 定向读取文件、符号、搜索和显式批量范围，
  使用 `analyze_code` 获取调用、类型、依赖、数据传播和任务 Diff；可在同一分析中附带
  所需源码。完整 Live 工具集合为 40 个，历史 Mirror 保持 15 个只读工具与原语义。
- **Python / Java 有界值传播**：支持值来源、影响、两值之间的静态路径及联合分析。
  Java 使用现有 Tree-sitter 前端；动态分派、外部实现、别名及未支持语义明确标为
  partial/unknown，无静态路径不证明运行时不可达。
- **分析覆盖与诊断**：区分已提取、受限、未分析及元数据遗漏；返回有界样本、诊断分类
  和预算限制。外部依赖区分标准库、声明第三方、本地不可用及未知来源。
- **受控批量写入**：`write_batch` 一次预检 1–20 项编辑、文件创建或逐级目录创建，
  复用逐项恢复与幂等记录。执行中断返回已完成和待处理项，不承诺多文件原子事务。
- **源码与恢复边界**：读取拒绝硬链接，严格检查请求字段；搜索、结构查询与结果都有
  预算。Darwin 暂存文件保留自身来源属性，历史准备阶段恢复仍核验原文件与登记材料。
- **本机工作区管理**：显示完整工作区与占用，支持将确认的派生工作区可恢复地移至
  废纸篓；源码、连接设置、密钥与写入恢复库保留。索引使用每项目独立 SQLite。
- **连接与待命体验**：保留重启身份修复、状态流读取修复和有活动保护的五分钟待命窗口。
  写入与开发档保持默认关闭。

独立 Rust 核心及只读流程代码位于 `native/`，仅用于可复现的评估，未注册生产 MCP
工具或接入生产授权、源码写入路径。结果与限制见 [Rust 试点](RUST_CORE_PILOT_20261016.md)
和[规模评估](RUST_SCALE_EVALUATION_20261016.md)。

## 源码运行与校验

```sh
git clone --branch v0.5.0b7 https://github.com/YuyanYYt/Colink.git
cd Colink
uv sync --locked
uv run colink live --root examples/sample_project --project sample \
  --data-dir .code-context/live-sample
```

该命令启动本地 stdio MCP；连接与项目授权仍由使用者配置。源码归档只包含公共仓库
文件，不包含维护者的配置、运行数据库、恢复备份、未跟踪样例或依赖缓存。
