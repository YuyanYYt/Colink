# CoLink 0.5.0 Beta 5 · build 22

2026-10-09 公开预发行。面向 Apple Silicon Mac，安装包声明最低 macOS 14；完整原生
运行验收在维护者的 macOS 27 上完成。Intel Mac 和 Windows 没有图形安装包。
本版从上一公开版 `v0.5.0b2` 更新，安装包内含 Python、
MCP 运行依赖和官方隧道客户端。

## 主要变化

- **三档本机授权**：只读、写入、开发分别控制；连接、退出或重启后写入和开发授权
  默认关闭。原文件读取、多项目和受控源码写入继续使用明确的项目 ID。
- **原生开发终端**：开发档可运行本机命令、交互程序和长期服务。项目授权决定入口
  与初始目录，终端随后按当前 macOS 用户权限访问文件、网络和数据库；它不是沙盒，
  也不经过源码写入协调器的回滚记录。
- **数据库入口调整**：只读和写入档只有固定的数据库读取工具；开发档可用已安装的
  CLI 或驱动及数据库账号的真实权限执行操作。旧数据库连接页、聊天卡片和逐库授权
  入口已移除。
- **代码索引与本机体验**：按项目保存当前结构索引，更新时尽量局部重建；可更换运行
  数据目录。加入受控文件移动、本地 Git 提交和更准确的执行状态。
- **build 22 修复**：同一进程执行 `exec` 时不再被误判为进程身份替换；进程组归属、
  用户身份和信号目标仍须复核。

## 下载与校验

- `Colink-macos-arm64.dmg`：推荐的拖放安装包。
- `Colink-macos-arm64.zip`：备用应用归档。
- `colink-code-context-skill.zip`：可选的调用指导，不会自动配置连接或授权。
- `SHA256SUMS`：在同一下载目录运行 `shasum -a 256 -c SHA256SUMS`。

## 验证与边界

build 22 的相关进程监管回归 72 项、完整本机回归 2,611 项通过；安装版 Python
在隔离探针中启动、监控并取消真实子进程，进程组清空。最终 DMG/ZIP 的校验值、
应用 build 22 身份和严格 ad-hoc 签名已核对。原安装版的项目选择与连接设置保留，
写入和开发授权关闭。原始范围见 [build 22 验收记录](EXECUTION_SCOPE_EXEC_FIX_20261009.md)。

发行版只有 ad-hoc 签名，未完成 Apple Developer ID 签名或公证。可选隔离执行器
目前只在已验证的 Darwin 27 开放；macOS 14 的 CI 只覆盖源码读取、写入、索引和
打包等可移植路径，未证明该系统上的完整原生运行能力。原生开发终端是另一条按当前
用户权限运行的路径。
本机及安装包测试不等于所有账号的网页工具、业务数据库或任意项目均已验收，也不
表示已上架 ChatGPT 公共插件目录。被查询的源码会发送给所用 AI 客户端及其服务
提供方。开发终端产生的文件、数据库与网络副作用不会因取消而自动撤销。
