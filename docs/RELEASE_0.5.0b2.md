# CoLink 0.5.0 Beta 2

让网页 AI 按需读取本机项目，并在你允许时精准修改代码。
这一版把此前的直读、多项目与受控写入功能带到可直接安装的 macOS 包中。

## 新增与变化

- **原文件按需直读**：直接读取磁盘上已保存的源码，不为普通读取保存完整项目镜像。
- **多项目管理**：一个工作目录登记多个项目，分别在本机确认；网页按项目选择。
- **Python / Java 代码关系**：按需查符号、引用、类关系、调用关系、模块/文件依赖、
  反向影响与依赖层级。不确定的静态分析结果不会伪装成完整依赖事实。
- **受控写入**：默认关闭；本机授权后支持准确行插入、范围/片段替换、创建文件与
  目录、删除单个源文件。修改前核对真实内容及哈希，任务 Diff 汇总多轮改动。
- **项目发现改善**：无 `.git` 的 Python/Java 项目也可依据配置发现；同名项目用
  路径限定名区分，保留原有人工名称、项目身份和访问许可。
- **代码历史交给 Git**：移除主动代码回退按钮与工具。修改重要项目前先保存稳定点；
  保留必要的有界 Diff 起点与未完成写入保护，不提供无限历史备份。
- **更清晰的首页和安装说明**：功能、下载与版本变化放在首页；开发和测试记录另放。

## 下载与安装

支持 **Apple Silicon / macOS 14+**，无 Intel、Windows 图形安装包。

- `Colink-macos-arm64.dmg`：推荐；打开后将应用拖入“应用程序”。
- `Colink-macos-arm64.zip`：备用应用归档。
- `colink-code-context-skill.zip`：可选自动匹配 Skill，不能代替应用或账号连接。
- `SHA256SUMS`：下载文件的 SHA-256 校验清单。

应用包含 Python、MCP 运行依赖与官方隧道客户端，不需要另装开发环境。
打开应用后使用自己的 Tunnel ID、运行密钥与 ChatGPT 工作区；首次连接从自带样例开始。
完整步骤见 [安装指南](https://github.com/YuyanYYt/Colink/blob/v0.5.0b2/docs/INSTALL.md)。

## 从旧版升级

先关闭并退出旧应用，再替换安装；保留原用户配置、凭据和持久化数据。
新版不自动删除旧镜像，也不自动开启连接或写入。更新后在 ChatGPT 原连接页刷新
工具并新建对话；账号里的旧 Skill 副本需单独更新。

新版提供十五项读取工具和七项任务工具，旧 `rollback_write_task` 已移除。
项目登记支持 schema 1/2；旧 Beta 1 不应直接读取已升级登记。历史下载继续保留，
但降级须先检查数据兼容性，不能直接删除用户数据绕过。

## 当前边界

- **Beta 预览**：仅 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证。
- 默认只读，写入仅限本机明确授权的项目；不增加递归删除或任意命令执行。
- 当前**没有终端工具**，不能替 AI 安装依赖、运行项目或提交/推送 Git。
- 私有连接不等于源码不出电脑；被查询的源码会发送给 AI 客户端及其服务提供方。
- 应用和源码发布不等于 ChatGPT 公共目录上架，也不保证每个账号都有同样入口。
- 本地、安装包、CI 与历史网页证据各有范围，不承诺任意项目或所有工具零缺陷。

详见 [读取与写入](https://github.com/YuyanYYt/Colink/blob/v0.5.0b2/docs/LIVE_USAGE.md)
和 [安全说明](https://github.com/YuyanYYt/Colink/blob/v0.5.0b2/SECURITY.md)。
