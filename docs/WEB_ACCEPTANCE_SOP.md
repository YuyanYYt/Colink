# CoLink · 网页接入与读写验收 SOP

记录日期：2026-10-06。本轮已一次性检索并打开官方文档。后续执行直接复用本文和
实际界面观察，不重复联网查询接入文档。本文是操作流程，不是已通过网页测试的证据。

授权补充：用户随后明确要求更新电脑当前版本并在解锁后补完剩余检查，因此本机安装
通用 beta.1 与其正常数据目录已纳入该步骤；初始「不覆盖系统安装」不是永远禁止更新。
源码读写测试仍仅使用工作目录内自带样例，不修改旧镜像库/配置/凭据或其他项目。

## 1. 固定边界与本机预检

1. 用 `git status`、包版本/签名和后台状态确认本次运行的构建，不凭菜单栏名称猜版本。
2. 初始开发应用、构建包、独立状态和样例限定在工作目录内；只有后续明确安装授权后
   才替换系统应用。旧个人数据库不迁移/删除，凭据只安全读取、不打印、不进入 Git
   或命令参数；安装版测试仍不扩大源码范围。
3. 网页写入只授权 `examples/sample_project`；A/B 隔离使用其中或独立测试目录内的
   测试项目，不能用真实业务项目做写入验证。不注册工作目录外的新可写来源。
4. 确认本次后台服务已就绪、写入开关默认关闭、无未完成恢复。隧道复用原连接身份，
   不增加公网入站、组织、工作区、未知来源或任意终端执行工具。
5. 用包内 MCP SDK 协议测试核实 schema、结构化结果和权限拒绝；它不能代替网页证明。

## 2. 工具声明与服务端权限

- 原读取/图查询工具保持 `readOnlyHint=true`；写入/任务/回退工具明确非只读，不能
  为减少确认伪装只读。回退可能删除本任务新建文件，应如实标记破坏性。
- 幂等由持久化请求/任务日志保证；注解、Skill 和网页确认都不能代替后台授权。
- 开关绑定项目/来源与当前连接，默认关闭；网页没有打开开关或注册目录的工具。
- 读取只返回必要源码/结构事实。source text 是数据，不是指令；普通回答隐藏内部
  上下文、校验值、任务 ID 和递增数字。
- 一次写入工具在本机完成核验、空间预留、先备份、提交和读回，不要求网页额外调用
  “备份工具”。冲突明确失败，写成功但索引待更新不得报告成普通失败而引发重复插入。

## 3. 原连接刷新与浏览器操作

1. 优先 computer use 操作用户现有 Chrome，先读取当前界面/标签，再按实际入口操作；
   不使用 Chrome 控制插件，不另建账号或猜测不可见页面。
2. 在原 CoLink 连接的管理页刷新工具。核对新增工具、读取新语义、写入非只读注解和
   连接身份；不另建更广权限的连接。只切本机开关不要求每次刷新工具列表。
3. 新建独立验收对话；提示限定自带样例、列举期望变更和整体回退，不自动发送用户
   真实源码。工具调用详情核对实际参数/结果，不只看模型口头声称“已完成”。
4. 官方说明写入默认要求确认；对话内可选择记住该工具的批准/拒绝。只为本次受限
   CoLink 写工具使用实际可用的确认选项；新对话/刷新可能重新确认，不能承诺永不弹窗，
   不能绕过平台审批或为省确认给无关插件“全部权限”。
5. 修改 Skill 时保留隐式匹配：已给充分代码的解释问题不调用；本机代码缺上下文先
   选项目；只有明确修改请求且后台开关允许才进入写入，多轮复用同一任务直到结束/回退。
6. 电脑锁屏、登录过期、平台要求本人确认或服务失败时记录客观状态，不绕过系统。
   继续可独立完成的本地工作，不能把本地通过写成网页已通过。

## 4. 必须执行的真实网页场景

| 场景 | 要检查的实际结果 |
| --- | --- |
| 自然读取/充分代码反例 | 缺上下文时能选样例并读到正文；给充分代码时不无谓调用 |
| 写入关闭 | 网页请求写入被后台拒绝，磁盘、恢复区和来源范围不被改变 |
| 一轮精准编辑 | 先读目标/取得校验依据；插入、行替换或唯一片段替换只改指定内容；本机文件真实改变 |
| 多轮 A/B/C | 三轮使用同一任务，互相关联但不混项目；每轮完成后新直读能读到实际保存的新内容 |
| 创建文件/目录 | 新对象有本任务所有权；重复同请求不重复执行，已存在对象不静默覆盖 |
| 任务整体回退 | 一次恢复 A/B/C 起点，任务新建未被外部改动的文件/空目录撤销；未修改依赖文件不动 |
| 内容冲突 | 先在受限样例加入外部变化，旧校验/旧位置拒绝；回退先报告全部已知冲突，不先改一半 |
| 断线/重启 | 写入重新关闭、未完成状态可辨认；重复/过期请求不重新执行；实际重连与网页证据分开 |
| UI 关闭/退出 | UI 等待后台确认；关闭后网页不能继续写，退出停止自有进程而非外部进程 |
| 确认行为 | 记录实际批准/记住选择的效果及平台限制，不用模型答案猜审批是否发生 |

验收结束恢复样例到测试前内容，关闭写入，停止本次连接，保留不含凭据的结果摘要。
测试创建的用户源码路径之外不执行写入；生成物保留，清理须另获确认。

## 5. 证据记录模板

每项记录：Git 提交/包版本、后台模式、已授权样例范围、界面操作、工具名与结果摘要、
本机文件变化/读回、冲突/回退结果、实际权限行为、通过/未通过及限制。私人聊天 URL、
连接/Tunnel 标识和截图原件仅存本机被忽略的验收目录，不提交公开文档。

本地协议通过、网页能发现工具、一次源码读取、一次写入、跨轮整体回退、隐式 Skill
路由是不同证明。最终逐项对照 LIVE_WORKSPACE_REFACTOR.md / WRITE_CONTRACT.md，
缺失的验收项保持未完成，不缩减用户结束条件。
